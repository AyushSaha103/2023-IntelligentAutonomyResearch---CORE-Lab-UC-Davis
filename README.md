# Intelligent Autonomy Research Projects (undertaken in CORE Laboratory @ UC Davis)
Presented at 2023 URSCA Research Conference

## PART 1
### Graph Temporal Neural Network for Traffic Forecasting

Concept: forecast traffic flow at various street intersections in METRLA Dataset, using 20+ minute forecast horizon, based on past traffic patterns

Development: Deep Learning algorithms GTNN and LSTM implemented from scratch, in C++

Evaluation Results:

For 20-minute lookahead traffic forecasting, 91% accuracy was achieved

## PART 2
### Adaptive Cruise Control System for F1TENTH Vehicle

Concept: Develop closed loop control system to control vehicle gas/brake pedals

--------> Optimize vehicle speed while maintaining safety

Finalization: Testing scripts developed in MATLAB to run control system in variety of road conditions, and behavioral patterns of lead vehicle

--------> We determined optimal set of parameters to control follower vehicle travel
